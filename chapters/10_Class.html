10  Class 10: Assembly with the IEN Array, and Quadrature on an Element

\[ (\mathrm{S}) \Longleftrightarrow (\mathrm{W}) \;\xRightarrow{\text{approximate}}\; (\mathrm{G}) \;\xRightarrow{\text{exact}}\; (\mathrm{M}) \]

Only one step in that chain loses anything: \((\mathrm{W}) \Rightarrow (\mathrm{G})\), where we restrict to a finite-dimensional subspace. \((\mathrm{S}) \Leftrightarrow (\mathrm{W})\) was proved both ways in Class 5, and \((\mathrm{G}) \Rightarrow (\mathrm{M})\) is just algebra.

And \((\mathrm{S})\) — the strong form itself — is already an (approximate) physics problem: the modelling assumptions were made before any of this machinery started.

\[ -\nabla\cdot\left(\underline{\underline{K}}\nabla u\right) = f \quad \text{in } \Omega \qquad\qquad u = g \quad \text{in } \Gamma_g \qquad\qquad \left(\underline{\underline{K}}\nabla u\right)\cdot\underline{n} = h \quad \text{in } \Gamma_h \]

Or, for elasticity, with \(\sigma_{ij,j} + f_i = 0\):

\[ -\nabla\cdot\underline{\underline{\sigma}} = \underline{f} \quad \left(\sigma_{ij,j} + f_i = 0\right) \quad \text{in } \Omega \qquad\qquad \underline{u} = \underline{g} \quad \left(u_i = g_i\right) \quad \text{in } \Gamma_{g_i} \qquad\qquad \underline{\underline{\sigma}}\,\underline{n} = \underline{h} \quad \left(\sigma_{ij}n_j = h_i\right) \quad \text{in } \Gamma_{h_i} \]

What is \(\Gamma_{g_1}, \Gamma_{g_2}\)? \(\Gamma_{h_1}, \Gamma_{h_2}\)? — Each component of displacement (or flux) can have its own Dirichlet or Neumann boundary, which need not coincide with the others. A pin support fixes both displacement components; a roller fixes only one.

To solve the big problem, approximately, we must first be able to solve on one element.

\[ \sum_B \left(\int_\Omega \nabla N_A \cdot \underline{\underline{K}}\nabla N_B\;d\Omega\right) d_B = \int_\Omega N_A f\;d\Omega + \int_{\Gamma_h} N_A h\;d\Gamma - \sum_B g_B \int_\Omega \nabla N_A \cdot \underline{\underline{K}}\nabla N_B\;d\Omega \]

we must first be able to solve, on one element \(\Omega^e\),

\[ \int_{\Omega^e} \nabla N_A \cdot \underline{\underline{K}}\nabla N_B\;d\Omega \qquad\qquad \int_{\Omega^e} N_A f\;d\Omega \qquad\qquad \int_{\Gamma_h^e} N_A h\;d\Gamma \]

12 The IEN array

The IEN (element \(\to\) node) array maps a local basis-function index \(a\) on element \(e\) to the global basis-function index \(A\): \(a, e \xrightarrow{\text{IEN}} A\).

\(a \backslash e\) \(e_0\) \(e_1\) \(e_2\) \(e_3\) \(e_4\)
\(a=0\) \(A=0\)
\(a=1\) \(5\)
\(a=2\) \(6\)
\(a=3\) \(7\)

(Finish the rest — each column follows the same pattern of walking around its own element’s four corners.)

13 Global stiffness from local (element) stiffness

\[ K_{AB} = \int_{\Omega} \nabla N_A \cdot \underline{\underline{K}}\nabla N_B\;d\Omega = \sum_e \int_{\Omega^e} \nabla_x N_A \cdot \underline{\underline{K}}\nabla_x N_B\;d\Omega \qquad \leftarrow \textbf{global stiffness} \]

Use the IEN array to only work on relevant basis functions: \(a, e \xrightarrow{\text{IEN}} A\), \(b, e \xrightarrow{\text{IEN}} B\).

\[ K_{ab}^e = \int_{\Omega^e} \nabla_x N_A^{(x)}\,\underline{\underline{K}}(x)\,\nabla_x N_B^{(x)}\;d\Omega \qquad \leftarrow \textbf{local stiffness, spatial domain} \]

Pulling this back to the reference domain, as in the last class:

\[ K_{ab}^e = \int_{\hat\Omega} \nabla_x N_a(\xi)\,\underline{\underline{K}}(x(\xi))\, \nabla_x N_b(\xi)\;J(\xi)\;d\hat\Omega \]

where \(\dfrac{\partial N_a}{\partial x_i} = \dfrac{\partial N_a}{\partial \xi_j}\dfrac{\partial \xi_j}{\partial x_i} = (DF^{-1})^T \nabla_\xi N_a\) — the inverse of the deformation gradient, from last class:

\[ K_{ab}^e = \int_{\hat\Omega} \left[(DF)^{-T}\nabla_\xi N_a\right] \underline{\underline{K}}\left[(DF)^{-T}\nabla_\xi N_b\right] J\;d\hat\Omega \qquad\Longrightarrow\qquad K_{ab}^e = \sum_{g=0}^{n_{quad}} w_g \left[(DF)^{-T}(\xi_g)\nabla_\xi N_a(\xi_g)\right] \underline{\underline{K}}(x^e(\xi_g)) \left[(DF)^{-T}(\xi_g)\nabla_\xi N_b(\xi_g)\right] J(\xi_g) \]

This sum over quadrature points \(g\) is what a finite element code evaluates for every element, every time it assembles \(\underline{\underline{K}}\).
