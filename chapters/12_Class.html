12  Class 12: The Spatial Mapping

From the parent domain to a physical element

Class 11 showed how to build 2D basis functions on the parent domain (also called the reference domain), the square \(\hat\Omega = [-1,1]^2\) with coordinates \((\xi,\eta)\). Elements in a mesh may not be squares, and if they are, they aren’t always centered around the origin, so we need a method that takes a point of the parent domain to a point of the element. That rule is the spatial mapping, and it uses the same basis functions. In two dimensions, this looks like

\[ \underline{x}^e(\xi,\eta) = \sum_{A=0}^{n_{en}-1} \underline{x}_A^e \, N_A(\xi,\eta), \]

where \(\underline{x}_A^e\) is the position of node \(A\) of element \(e\), and \(n_{en} = (p_\xi+1)(p_\eta+1)\) is the number of nodes on the element. The above equation can be represented by two coordinate mappings for both the \(x\) and the \(y\) coordinates from the parent domain as

\[ x(\xi,\eta) = \sum_A x_A\,N_A(\xi,\eta), \qquad y(\xi,\eta) = \sum_A y_A\,N_A(\xi,\eta). \]

Compare this with the approximate solution,

\[ u^h(\xi,\eta) = \sum_A d_A\,N_A(\xi,\eta). \]

Both of these maps use the same basis functions but different coefficients, which coefficients are defined by the nodal positions of the element geometry. Using the same \(N_A\) for both the solution, \(u^h,\) and for the geometry is what isoparametric means.

12.1 The general form

If we write \(\underline{\xi}\) for the parametric coordinates, \(\underline{\xi} = (\xi,\eta)\) in 2D and \(\underline{\xi} = (\xi,\eta,\zeta)\) in 3D. Then

\[ \underline{x}^e(\underline{\xi}) = \sum_{A=0}^{n_{en}-1} \underline{x}_A^e \, N_A(\underline{\xi}), \]

with the basis functions and the single index built as in Class 11,

\[ N_A(\underline{\xi}) = \prod_{i=0}^{n_{sd}-1} \ell^{p_i}_{a_i}(\xi_i), \qquad A = \sum_{i=0}^{n_{sd}-1} a_i\,s_i, \qquad s_0 = 1, \quad s_i = \prod_{j=0}^{i-1}(p_j+1), \]

and \(n_{en} = \prod_{i=0}^{n_{sd}-1}(p_i+1)\). In 2D this is \(N_A(\xi,\eta) = \ell^{p_\xi}_a(\xi)\,\ell^{p_\eta}_b(\eta)\) with \(A = a + (p_\xi+1)b\), which is what the viewer below uses. The interpolation points are typicallly equally spaced in each direction.

12.2 The map, interactively

The left panel is the parent domain, the right is the physical element. The element you start with is a quarter annulus, \(1 \le r \le 2\), with its nodes placed at the parametric node locations.

  • Drag the dot in the parent domain, or type \(\xi\) and \(\eta\) below it. The matching point in the physical element follows.
  • Drag the gold control points in the physical element, or edit their coordinates in the table. The element changes shape.
  • Nodes in the parent domain are drawn scaled by \(N_A(\xi,\eta)\) at the current point, so a large marker means a large weight. Blue is a positive weight, red a negative one.

12.3 Reading the four lines

The block to the right of the table is the same computation written four times.

  1. The sum, symbolically. One term per node, so the number of terms changes with the degree: \(n_{en} = (p_\xi+1)(p_\eta+1)\).
  2. Nodal coordinates substituted. The \(\underline{x}_A\) are now numbers, the ones in the table. The parametric point has not been used yet.
  3. Basis functions evaluated. Now \((\xi,\eta)\) is used and each \(N_A\) becomes a number. This is the only line that changes when you move the dot without changing the element.
  4. The mapped point. Multiply and add.

The term in red has the largest weight. Move the dot to a node and that weight becomes \(1\) while the others become \(0\), which is the interpolation property from Class 11.

Below the table is the running value of \(\sum_A N_A(\xi,\eta)\), which is \(1\) everywhere. This is the partition of unity, and it says a constant is reproduced exactly: if every \(\underline{x}_A\) were the same point, the map would return that point for any \((\xi,\eta)\). It is the \([0,0]\) case of the reproduction question in Homework 6, Problem 3.

12.4 The basis functions

This page does not plot the 2D basis functions. The node markers in the parent domain show \(N_A(\xi,\eta)\) at the current point, which is what is needed here. To see the surfaces themselves, go back to Class 11.

12.5 Things to try

  1. Drag the dot to the corner \((\xi,\eta) = (-1,-1)\). The mapped point is control point \(0\), and in line 3 every weight is zero except that one.
  2. Set \(p_\xi = p_\eta = 1\). There are four nodes and the edges are straight: a bilinear map cannot curve an edge. The mapped grid lines are still not parallel, so the map is not affine.
  3. Go back to degree 2 and drag the mid-edge control point \(A = 1\), at \((a,b) = (1,0)\), away from the edge. The edge bends. This is how a quadratic element follows a curved boundary.
  4. Keep moving that node past its neighbours until the mapped grid lines cross. The map is no longer one-to-one and the element has folded. Nothing in the sum prevents this.
  5. Set \(p_\xi = 3\), \(p_\eta = 1\): cubic in \(\xi\), linear in \(\eta\), eight nodes. The stride \(A = a + (p_\xi+1)b\) renumbers the table.
  6. Put the dot at \((\xi,\eta) = (0,0)\) and read line 3. At degree 2 in both directions the centre node has weight \(1\) and the rest have weight \(0\); at degree 1 the four corners each have weight \(0.25\). The centre of the element is a node only when the degree is even.

12.6 Next

The map says where a parametric point goes. It does not say how much a small piece of the parent domain is stretched or rotated on the way, and we need that to write \(\int_{\Omega^e} (\cdot)\,d\Omega\) as an integral over the parent domain that quadrature can evaluate. Differentiating the sum with respect to \(\underline{\xi}\) gives the deformation gradient and its determinant, the Jacobian, in Class 13. Item 4 above is the case where that determinant changes sign.
