16  Class 16: Derivatives of the Solution

What we actually compute when we ask for strain, flux, or error

The solution \(u^h\) is built from basis functions. However, many quantities of interest, such as strain, stress, and flux, are built from the derivatives of \(u^h\). The derivative of the solution is built from the derivative of the basis functions used to approximate \(u^h\). This page aims to clarify that difference in one dimension and visually shows why approximation error is larger for these quantities of interest and describes how fast that error can shrink.

16.3 Why this matters for error

Pushing the sliders should clarify two things. First, the approximation of \(u\) looks good long before the approximation of \(du/dx\) does, and second the derivative for Lagrange basis functions are never required to be continuous.

To talk how error deteriorates, we need to be able to measure the energy of the error. To do so, we will use Sobolev norms. In one dimension, these look like

\[ \|e\|_{H^0(\Omega)}^2 = \int_\Omega e^2 \, d\Omega, \qquad \|e\|_{H^1(\Omega)}^2 = \int_\Omega e^2 + \left(e_{,x}\right)^2 d\Omega, \]

and in general \(\|e\|_{H^s}\) includes every derivative up to the \(s\)-th. \(H^0\) is the same thing as \(L^2\): it only asks whether the values are close. \(H^1\) also asks whether the slopes are close — which, as the lower plot shows, is a harder thing to get right.

Approximation of a derivative, as opposed to a solution, reduces the convergence rate by one, meaning that the exponent on \(h\) (the size of the mesh, which forces error down as \(h\) decreases) decreases by one.

\[ \|e\|_{H^s(\Omega)} \;\leq\; C \, h^{\beta} \, \|u\|_{H^{k+1}(\Omega)} \]

where typically in this class \(\beta = k+1-s\). Each derivative we want to measure in our error decreases accuracy by a power of \(h\). At degree \(k\), the solution converges at rate \(k+1,\) while the slope of the solution converges at rate \(k\). This will be made more precise and more concrete in the next class, where error estimates will be discussed more completely. We will also discuss how to measure the convergence rate, \(\beta\) in a software code to make sure that the finite element solver is working correctly.
